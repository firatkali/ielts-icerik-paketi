## Bölüm 1 — Academic pasajlar `A01`–`A12`

### Nereden alınacak (SADECE bu üçü)

| Kaynak | Adres | Lisans |
|---|---|---|
| PLOS dergileri | `journals.plos.org` (PLOS ONE, PLOS Biology, PLOS Climate, PLOS Global Public Health…) | CC BY 4.0 |
| ABD kamu kurumları | `nasa.gov`, `noaa.gov`, `usgs.gov`, `science.nasa.gov`, `earthobservatory.nasa.gov` | Kamu malı |
| OpenStax | `openstax.org` ders kitapları (Biology, Sociology, World History, Principles of Economics, Psychology) | CC BY 4.0 |

Başka hiçbir siteden metin alma. Wikipedia ve The Conversation **yasak**.

WebSearch + WebFetch kullanarak metinleri bul ve indir.

### Konu dağılımı (12 pasaj)

Gerçek sınavdaki gibi çeşitli olmalı. Şu dağılımı hedefle:

| Konu | Pasaj sayısı |
|---|---|
| Doğa / ekoloji / hayvan davranışı | 3 |
| İklim, jeoloji, okyanus | 2 |
| Uzay ve gezegen bilimi | 1 |
| Tarih ve arkeoloji | 2 |
| Toplum, eğitim, iş dünyası | 2 |
| Sağlık ve insan davranışı | 2 |

Aynı konudan iki pasaj birbirine çok benzemesin.

### Uyarlama kuralları

Kaynak metin ham hâliyle kullanılamaz. Şunları yap:

1. **Uzunluk: 700–900 kelime.** Uzunsa kes, kısaysa aynı makalenin başka bölümlerini
   ekle. Kelime sayısını gerçekten say, tahmin etme.
2. **Paragrafları harflendir: A, B, C, …** — 7 ile 10 arası paragraf olsun. (Başlık
   eşleştirme ve bilgi eşleştirme soruları buna dayanacak.)
3. **Akademik ama genel okur için anlaşılır dil.** Uzmanlık gerektiren formül, istatistik
   tablosu, atıf numarası (`[12]`), şekil göndermesi ("see Fig. 3") temizlenir.
4. **Cümleleri sadeleştirebilirsin** ama anlamı değiştirme. Lisans buna izin veriyor
   (CC BY türev serbest, atıf şart).
5. Metne uygun **kısa bir başlık** yaz.
6. Metnin sonuna ekleme yapma, uydurma bilgi katma.

### Kalite kontrolü (her pasaj için)

- [ ] 700–900 kelime (sayıldı)
- [ ] 7–10 harflendirilmiş paragraf
- [ ] Her paragrafın **ayırt edilebilir tek bir ana fikri** var (başlık eşleştirme için şart)
- [ ] En az 3 paragrafta somut sayı/tarih/isim var (tamamlama soruları için şart)
- [ ] En az 2 yerde yazarın görüş/değerlendirme cümlesi var (YES/NO/NOT GIVEN için şart)
- [ ] Kaynak adresi çalışıyor, lisans CC BY veya kamu malı
- [ ] "IELTS" kelimesi geçmiyor

## Bölüm 2 — General Training metinleri `G01`–`G06`

GT okuması akademik değildir: günlük hayat ve iş yazışmalarıdır. Format için
`referans/text/ielts-general-reading-sample-tasks-2023.txt` dosyasını oku (yoksa
`referans/ielts-general-reading-sample-tasks-2023.pdf` dosyasını Read ile aç).

### `G01`, `G02` — 1. bölüm: günlük yaşam metinleri (ORİJİNAL YAZ)

Her kimlik **5 kısa metin** içerir, `A`–`E` harfleriyle işaretli, toplam ~400 kelime.
Bunlar bilgi verici günlük metinlerdir:

Örnek türler: bir belediye kütüphanesinin üyelik duyurusu · bir spor merkezinin kurs
takvimi · şehir içi ulaşım kartı kuralları · bir apartmanın çöp/geri dönüşüm talimatı ·
bir festival programı · bisiklet kiralama şartları · bir dil kursunun kayıt bilgisi.

Bu metinleri **kendin yazacaksın** (telif yok). Kurallar:
- Her metin 60–100 kelime, kendi başlığı var
- İçinde **somut ayrıntı** olsun: saat, ücret, tarih, telefon biçimi, koşul, istisna
- 5 metin **birbirine benzer konuda** olsun (hepsi "şehirdeki tesisler" gibi) ki
  eşleştirme sorusu anlamlı olsun
- Uydurma yer/kurum isimleri kullan (gerçek şirket adı yasak)
- İngiliz İngilizcesi yazımı (`centre`, `programme`, `organise`)

### `G03`, `G04` — 2. bölüm: iş ve eğitim metinleri (ORİJİNAL YAZ)

Her kimlik **2 metin** içerir, toplam ~500 kelime. İş hayatıyla ilgili:

Örnek türler: yeni çalışan el kitabından bir bölüm · şirket içi eğitim programı duyurusu ·
izin/mesai politikası · staj başvuru rehberi · uzaktan çalışma kuralları · iş yerinde
güvenlik yönergesi.

Kurallar `G01`/`G02` ile aynı; ek olarak:
- Metinler paragraflara ayrılsın ve paragraflar **A, B, C…** ile harflendirilsin
- Madde listeleri, alt başlıklar kullan (gerçek belge gibi görünsün)

### `G05`, `G06` — 3. bölüm: uzun genel ilgi metni (CC BY KAYNAKTAN)

750–900 kelime, Academic pasajlarla **aynı kaynaklardan** (PLOS/NASA/NOAA/USGS/OpenStax)
ama konu daha popüler ve anlatı ağırlıklı olmalı: örneğin uyku bilimi, şehirde bisiklet
kültürü, gıda israfı, ev bitkileri ve hava kalitesi, gönüllü çalışmanın etkisi.

Uyarlama kuralları Academic ile aynı (paragraf harflendirme dahil), tek fark: dil daha
sade, terim yükü düşük.

## Çıktı biçimi

Her pasaj **ayrı bir JSON dosyası**:
- Academic → `passages/academic/A01.json` … `A12.json`
- General → `passages/general/G01.json` … `G06.json`

```json
{
  "schema_version": "1.0",
  "passage_id": "A01",
  "module": "academic",
  "section": null,
  "title": "How Desert Ants Find Their Way Home",
  "topic": "doğa / hayvan davranışı",
  "word_count": 842,
  "paragraphs": [
    { "label": "A", "text": "..." },
    { "label": "B", "text": "..." }
  ],
  "texts": null,
  "source": {
    "origin": "PLOS Biology",
    "title": "Path integration in Cataglyphis ants",
    "url": "https://journals.plos.org/plosbiology/article?id=...",
    "license": "CC BY 4.0",
    "attribution": "Adapted from ... published in PLOS Biology under CC BY 4.0.",
    "adapted": true
  },
  "notes": "Kısaltıldı, atıf numaraları ve şekil göndermeleri temizlendi."
}
```

**General Training farkları:**
- `module`: `"general"`
- `section`: `1`, `2` veya `3`
- 1. ve 2. bölüm için `paragraphs` **null**, bunun yerine `texts` dolu:
  ```json
  "texts": [
    { "label": "A", "heading": "Riverside Library — Membership", "text": "..." },
    { "label": "B", "heading": "...", "text": "..." }
  ]
  ```
- 3. bölüm için `paragraphs` dolu, `texts` null
- Orijinal yazılan metinlerde:
  ```json
  "source": { "origin": "orijinal", "url": null, "license": "proje içi üretim",
              "attribution": null, "adapted": false }
  ```

Ayrıca `passages/INDEX.json` dosyasını oluştur/güncelle — tüm pasajların özeti:

```json
[
  { "passage_id": "A01", "module": "academic", "title": "...", "topic": "...",
    "word_count": 842, "paragraph_count": 9, "assigned_test": "AC1", "position": 1 }
]
```

`assigned_test` ve `position` değerlerini `content/PLAN-soru-dagilimi.md` içindeki
"Pasaj → test eşlemesi" tablosundan al.

## Bitirmeden önce

1. Ürettiğin her pasajın kelime sayısını gerçekten say (`wc -w` veya python), aralıkta mı kontrol et.
2. `passages/INDEX.json` güncel mi bak.
3. `NOTLAR.md` dosyasının sonuna bu çalıştırmayı ekle: hangi kimlikler üretildi, hangi
   kaynaklardan, atlanan/değiştirilen bir şey var mı.
4. Commit + push:

```
git add -A
git commit -m "pasaj: A01-A06 (PLOS/NASA/OpenStax, CC BY)"
git pull --rebase
git push
```

Commit mesajını ürettiğin gruba göre yaz. Push hata verirse `git pull --rebase` + `git push` tekrarla.

**Kullanıcıya soru sorma.** Bir kaynak bulunamıyorsa başka bir kaynağa geç, kararı
`NOTLAR.md`'ye yaz.
